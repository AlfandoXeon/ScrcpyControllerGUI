Section 01

Prerequisites & Android USB Setup

Xeon Scrcpy Controller uses the Android Debug Bridge (ADB) to manage and mirror connected hardware. Ensure USB Debugging is authorized on your target device before starting.

Enabling USB Debugging

  • Open Settings > About Phone on your Android device.
  • Tap Build Number repeatedly (7 times) until the prompt confirms developer mode is unlocked.
  • Navigate to Settings > System > Developer Options.
  • Enable the USB Debugging toggle.
  • Connect your device via USB cable and select Always allow from this computer on the authorization prompt.

Wireless TCP/IP Pairing

To run without a physical cable over local Wi-Fi, click the Wireless ADB button in the application, or execute: 

adb tcpip 5555
adb connect <DEVICE_IP_ADDRESS>:5555
Section 02

Screen Mirroring Parameters

The display panel exposes core parameters used by the hardware video encoder on your Android device.

Video Codecs

  • H.264 (AVC): Universal compatibility across all Android 5.0+ devices.
  • H.265 (HEVC): Offers approximately 40% higher compression efficiency. Best suited for high-resolution displays or wireless Wi-Fi streaming.
  • AV1: Next-generation open video format supported by modern processors (Snapdragon 8 Gen 2+, Dimensity 9200+, Tensor G3+).

Tuning Limits

  • Max Resolution: Caps the longest dimension (e.g. 1920 or 1280) to decrease USB bus load.
  • Max Framerate: Options from 30 up to 120 FPS.
  • Bitrate: Values between 8M and 16M offer an ideal balance of visual fidelity and low latency.
Section 03

Audio Forwarding Setup

Capture internal audio directly from Android 11+ devices and forward it to PC speakers or headphones.

Supported Codecs

  • OPUS: Default high-fidelity, low-latency audio codec.
  • AAC: Standard MPEG-4 audio profile with broad platform compatibility.
  • FLAC: Lossless audio compression for sound verification.
  • RAW: Uncompressed PCM audio stream.

Audio Duplicate

Enabling --audio-dup plays audio on both the host computer and the phone simultaneously.

Section 05

Hardware OTG Simulation Mode

OTG mode configures your host computer as a physical USB Human Interface Device (HID) connected to the phone.

Key Advantages

  • Zero Battery & Screen Overhead: Video encoding is completely bypassed, keeping device temperatures and battery usage minimal.
  • Linux UHID Driver: Operates at kernel level, bypassing Android OEM accessibility restrictions.
  • Zero Latency: Input events register as genuine hardware keystrokes and mouse movements.
Section 06

Device Power & Recovery Management

The Tools panel provides direct reboot triggers for maintenance and debugging workflows.

Reboot Actions

  • Reboot System: Standard warm operating system reboot.
  • Reboot Recovery: Direct transition into the recovery partition (stock or custom recovery).
  • Reboot Bootloader / Fastboot: Enters Fastboot mode for device maintenance or ROM flashing.

Handling Recovery Mode Safely

When a device is in recovery mode, Android records a boot instruction on the misc partition (Bootloader Control Block). If you force-power-off during recovery, the bootloader will run a filesystem consistency check (fsck) on subsequent boot, making the boot logo display longer than normal. To exit recovery safely, always use the Volume keys to select "Reboot system now" and press the Power key.

Section 07

Interactive ADB Shell Terminal

An integrated PyQt command prompt for executing raw ADB shell commands with asynchronous output streaming.

Safety Confirmation

Because raw shell access provides complete control over the device, an interactive confirmation dialog is displayed before starting a session.

Diagnostic Quick Chips

  • pm list packages -3: List all user-installed applications.
  • getprop: Inspect device properties and Android OS build info.
  • df -h: Check mounted storage usage and free disk space.
  • dumpsys battery: Inspect battery percentage and charging health.
Section 08

Xiaomi / HyperOS / MIUI Setup

Xiaomi devices running MIUI or HyperOS enforce an extra security restriction on software input event injection.

Fixing the INJECT_EVENTS Permission

  • Navigate to Settings > Additional Settings > Developer Options.
  • Locate USB Debugging (Security Settings) below the main USB Debugging switch.
  • Turn it on and confirm the prompt (requires active SIM card and logged-in Mi Account).

Alternatively, switch to OTG Mode in Xeon Scrcpy Controller. OTG Mode uses hardware simulation and does not require this setting.
